\section{Conclusion}
\label{sec:conclusion}

Raw retrieval is a strong memory for text, but when the evidence lies in images it leaves evidence sets incomplete. Visibility-Gated Set Reading lets a model navigate an index of the whole history to return the evidence set, after checking that the index can show it. It improves a lightweight reader on every benchmark and a strong reader wherever the index exposes the evidence, beyond both retrieval and six recent memory systems; the gain comes from reading the index rather than ranking by similarity, and index visibility decides which reading works. Memory for multimodal agents should be retrieved as sets, and the index decides whether a model can find them.
