\section{Related Work}
\label{sec:related}

\paragraph{Memory construction and raw retrieval.} Agent memories score a memory stream~\citep{park2023generative}, page context between tiers~\citep{packer2023memgpt}, extract and link notes~\citep{chhikara2025mem0,xu2025amem}, compress dialogue into facts and extend them to images~\citep{liu2026simplemem,liu2026omnisimplemem}, deduplicate extracted memories~\citep{chen2026telemem}, route inputs to typed memory agents~\citep{wang2025mirix}, build entity-centric multimodal memories~\citep{long2025m3agent}, weight memories by confidence~\citep{lu2026mma}, or route retrieval by modality over raw rounds~\citep{kang2026vmem}. Controlled studies find that raw-history retrieval matches or exceeds such systems~\citep{bao2026rawrag,zhou2026explicit,peng2026memorytax}, and our comparison extends this finding to image-dependent memory.

\paragraph{Navigation and selection.} ReadAgent looks up pages from gist memories~\citep{lee2024readagent}, MemWalker navigates a tree of summaries~\citep{chen2023memwalker}, an agent of LongMemEval-V2 explores stored trajectories~\citep{wu2026lmev2}, rankers order or grade candidates~\citep{sun2023rankgpt,zhuang2024beyond}, and one selection call can replace fact extraction for text memory~\citep{sharma2026selection}. \vgs{} returns a set of model-chosen size from a flat multimodal index and checks a measured property of the index before navigating; set-level goals also drive multi-hop retrieval~\citep{yang2018hotpotqa,gutierrez2024hipporag} and high-recall review~\citep{cormack2015autonomy}.

\paragraph{Multimodal memory and reading aids.} MemEye~\citep{guo2026memeye}, Mem-Gallery~\citep{bei2026memgallery}, MemLens~\citep{ren2026memlens}, and newer benchmarks~\citep{liu2026worldmemarena,chai2026smmbench,jiang2025memoryqa,nguyen2026personalvisual,tang2026dmvbench} evaluate memory over conversations with images, and a survey organizes these designs~\citep{guo2026seeingsurvey}. Chain-of-Note writes a note for every retrieved document~\citep{yu2023chainofnote}, whereas \vgs{} writes notes only for selected members, and a concurrent study finds on MemLens that the form in which memory reaches the reader matters more than perfect retrieval~\citep{jiang2026delivery}. Our cached compact index builds on prompt compression and attention reuse~\citep{jiang2023llmlingua,gim2023promptcache,jeong2024adaptiverag,zhang2026mempilot}.
