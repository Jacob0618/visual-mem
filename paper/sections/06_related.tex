\section{Related Work}
\label{sec:related}

\paragraph{Memory construction versus raw retrieval.} Agent memory systems differ in how much they transform the history before a question arrives. Generative agents score a memory stream by recency, importance, and relevance~\citep{park2023generative}; MemGPT pages context between memory tiers under model control~\citep{packer2023memgpt}; Mem0 and A-MEM extract, consolidate, and link memory notes~\citep{chhikara2025mem0,xu2025amem}; M3-Agent builds entity-centric episodic and semantic memories from multimodal streams~\citep{long2025m3agent}; and MMA reweights retrieved multimodal items by a reliability score to counter stale or conflicting evidence~\citep{lu2026mma}. Recent controlled studies find that raw-history retrieval matches or exceeds such systems on LoCoMo, LongMemEval, and related benchmarks~\citep{bao2026rawrag,zhou2026explicit}, that raw turns selected by one model call can replace extracted facts at tight budgets~\citep{sharma2026selection}, and that designed memory mainly helps weak models~\citep{peng2026memorytax}. Our text results replicate the large-budget form of this observation; our multimodal results identify set completeness as a limit of top-$k$ similarity and show that a query-time remedy helps only under measurable conditions.

\paragraph{Multimodal memory benchmarks.} MemEye~\citep{guo2026memeye} and Mem-Gallery~\citep{bei2026memgallery} evaluate memory over conversations with shared images, and MemLens~\citep{ren2026memlens} compares long-context models and memory agents on multi-session conversations whose visual necessity was validated by image ablation; it reports that long-context models degrade with length while memory agents lose visual fidelity under storage-time compression. LongMemEval-V2~\citep{wu2026lmev2} evaluates experience memory for web agents over trajectories with screenshots and finds that a coding agent that explores stored trajectory files outperforms retrieval, and Visual Haystacks~\citep{wu2025visualhaystacks} tests retrieval over large image collections, including questions over several needle images. WorldMemArena~\citep{liu2026worldmemarena} evaluates the writing, maintenance, retrieval, and use of multimodal memory over long multi-session tasks, and we use its lifelong part as an external test; SMMBench~\citep{chai2026smmbench} requires composing evidence that is distributed across independent sources, Memory-QA~\citep{jiang2025memoryqa} answers recall questions over stored visual memories, possibly from several memories at once, and two benchmarks target evidence that only the pixels carry, personal visual memory~\citep{nguyen2026personalvisual} and DMV-Bench~\citep{tang2026dmvbench}. The contrast between MemEye and MemLens in our study suggests that benchmarks differ in a property that matters for memory design, namely how visible the evidence is to a compact index, and the pixel-only benchmarks are natural stress tests for any index built from descriptions; a recent survey organizes these designs~\citep{guo2026seeingsurvey}.

\paragraph{Navigation over an index.} Several methods let a language model navigate a compact representation before reading the original text. ReadAgent compresses a long document into gist memories and looks up pages that the task requires~\citep{lee2024readagent}; MemWalker navigates a tree of summaries~\citep{chen2023memwalker}; and the coding agent of LongMemEval-V2 explores stored trajectory files~\citep{wu2026lmev2}. \qss{} belongs to this family and differs in returning an unordered evidence set whose size the model decides, over a flat index of a personal history, with multimodal content kept raw. Our results add a caveat that applies to the whole family: navigation can only reach evidence that the compact representation exposes, which index visibility quantifies.

\paragraph{Language models as rerankers and selectors.} Listwise reranking orders a candidate list by relevance~\citep{sun2023rankgpt}, pointwise rankers score candidates with graded relevance labels~\citep{zhuang2024beyond}, and selection with a single model call can replace extraction for text memory~\citep{sharma2026selection}. Adaptive retrieval chooses a retrieval strategy according to the estimated complexity of the question~\citep{jeong2024adaptiverag}. Our same-model controls compare the set formulation with listwise ranking, with and without a recall-oriented instruction, and with graded relevance under a dynamic cut-off; they attribute most of the recall to model judgment and to the instruction, and a smaller part to the set output, while the number of rounds that a model returns depends strongly on its family and on prompt calibration.

\paragraph{Set-level evidence and high recall.} Multi-hop question answering scores whether all supporting facts are found~\citep{yang2018hotpotqa}, and multi-hop retrieval reports all-recall, the fraction of questions whose relevant passages are all retrieved~\citep{gutierrez2024hipporag}. High-recall retrieval for technology-assisted review aims to find nearly every relevant document~\citep{cormack2015autonomy}. Full-set recall applies these goals per question to agent memory, where the members of a set are often named by references to the history rather than by their content.

\paragraph{Write-time organization and learning from use.} GraphRAG answers global questions with community summaries written at indexing time~\citep{edge2024graphrag}, RAPTOR retrieves from a tree of recursive summaries~\citep{sarthi2024raptor}, HippoRAG retrieves over a knowledge graph~\citep{gutierrez2024hipporag}, and document expansion predicts the queries that a document will answer~\citep{nogueira2019doc2query}. The write-time organizations that we tested, groups and predicted aliases written by a strong model, recovered little for set queries in personal memory. Resolution write-back instead learns from use, like MemPrompt, which stores corrections of misunderstood requests for similar queries~\citep{madaan2022memprompt}, and ExpeL, which accumulates insights from past task attempts~\citep{zhao2024expel}; it stores resolved evidence sets of one user history.

\paragraph{Reading aids and inference cost.} Chain-of-Note lets a reader write a reading note for each retrieved document and judge its relevance before answering~\citep{yu2023chainofnote}. The per-member notes of VGS follow the same idea but are written only for the members of a selected set, only when the estimated index visibility is low, and are kept next to the raw rounds rather than in place of them. Prompt compression removes low-information tokens with a small language model to shorten long prompts~\citep{jiang2023llmlingua}; our compact index applies deterministic rules to the index lines only, which leaves the content that the reader sees unchanged. A concurrent study isolates delivery, the form in which retrieved multimodal memory reaches the reader, and finds on MemLens that delivery matters more than perfecting retrieval~\citep{jiang2026delivery}; the per-member notes of VGS are one delivery decision of this kind, made only for low-visibility questions. Prompt Cache reuses the attention states of prompt segments that recur across requests~\citep{gim2023promptcache}; we rely on the context cache of a commercial API for the per-user index and measure what it saves. Set-aware routing resembles adaptive retrieval in deciding per question whether the expensive path is needed~\citep{jeong2024adaptiverag}, and MemPilot learns, with reinforcement learning, when to retrieve from query-agnostic memory and when to curate memory for the query under preferences for performance, cost, and latency~\citep{zhang2026mempilot}, whereas our router and gate are fixed rules whose conditions are measured.

\paragraph{Long-context reading.} Long-context models use evidence unevenly across positions~\citep{liu2024lost}. We observe a related effect for lightweight multimodal readers on MemEye, whose full-context accuracy drops from 0.495 to 0.368 as the history grows 32-fold, whereas on MemLens their full-context accuracy changes little from 32k to 128k. Sampling consensus in our lightweight selector follows self-consistency~\citep{wang2023selfconsistency}, applied to sets of selected rounds rather than to answers.
