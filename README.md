## Code
- `src/gem.py` — Gemini client: sqlite response cache (re-runs are free and bit-identical), retries/timeouts,
  Files-API image upload, per-call usage log (`cache/usage.jsonl`) and USD accounting (incl. cached-token price).
- `src/data_mm.py`, `src/data_text.py` — loaders. `src/mm.py` — captioning (write-time rewriting), round keys,
  retrieval, prompt rendering at a chosen media resolution, MemEye judge. `src/textmem.py` — text baseline +
  LongMemEval official judge + Mem0 judge. `src/scale.py` — distractor-grown haystacks.
- `scripts/run_mm.py` — conditions `"<selection>|<representation>"`, e.g. `fc|raw:low`, `cap:dense:10|raw:low`,
  `oracle|cap:short`, `fc+cap:dense:10|mix:low:high`; `scripts/retrieval_mm.py` — retrieval-only diagnostics;
  `scripts/run_text.py` — text runs; `scripts/analyze.py` — paired bootstrap tables; `scripts/make_tables.py`.

## Phase 2 (capability methods: set-level recall, reader-driven zoom, ...)
- `src/mm2.py` — table-of-contents (TOC) selection (`toc_select`, optional cosine prefilter), chunked scan, caption-space
  graph expansion, write-time group index, map-reduce reading, reader-driven zoom (`zoom2_read`, in-place `zoom3_read`,
  blind control `blind_zoom_read`), hint reading.
- `scripts/run_mm2.py` — conditions `"<selector>|<reader-mode>:<res>"`, e.g. `toc38:40|read:medium`,
  `ptoc38:200:40|read:low`, `toc38:40|zoom2f:medium`, `rag:20|mr:high`; records total usage/$ over ALL calls.
  Reader via `--reader` (main: `gemini-2.5-flash-lite`; control: `gemini-3.8-flash`); `--grow 1000` for the scale test;
  `--bench memgal --split all --qids results/memgal_subset.json` for Mem-Gallery.
- `scripts/select_eval.py` — selection-only set-level recall (full-set recall vs cosine at the same size).
- `scripts/analyze_p2.py`, `scripts/make_tables_p2.py` -> `results/TABLES_P2.md`; warm-cache cost estimate:
  `results/mm2/cost_warmcache.md`. Phase-2 decisions/failures: `notes/RESEARCH_LOG.md` (P2-D0 ... P2-D8).

## Development protocol behind the ACL paper (`paper_acl/`)
- **Development data**: MemEye (all 371 questions) and the MemLens development split (233 questions,
  `results/memlens_p5_split.json`). The index format, all prompts, the two reading paths of VGS, and the gate threshold
  tau = 0.7 were designed on these data.
- **Evaluation-only data**: the MemLens test split (466 questions, 32k and 64k histories) and VisualMem (696
  questions). Each hypothesis on these data was written down before its first run (`notes/RESEARCH_LOG.md`: P4-D2,
  P5-D8, P6-D4, P7-D1 for MemLens; P10-D0 for VisualMem). The VisualMem inclusion check was amended before VGS was run
  on it (top-40 retrieval with and without images -> annotated evidence with and without images; P10-D5).
- **Strong reader on MemLens**: an abstention deferral (answer of the lightweight reader when the strong reader
  declines) was added after the 32k test split had been seen. The paper no longer uses it: the strong widened path is
  plain top-40 retrieval (`STRONG_DEFER = False` in `scripts/p11_analyze.py`, `DEFER = False` in
  `scripts/p10_unified.py`; phase 14 in `REPORT.md`).
- **External memory systems** (phases 11-12): released code with default settings, the same Gemini models for every
  system, our readers and judges, and the 150-question MemLens subset `results/p11_memlens_sub150.json`; per-system
  notes and the code changes needed to run them are in `REPORT.md` (phases 11-12) and `scripts/p11_*.py`, `scripts/p12_*.py`.
